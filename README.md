## 📌 Project Overview

This project focuses on analyzing global superstore sales data using Python. It explores sales performance, profitability, product categories, customer segments, regional performance, and business trends through Exploratory Data Analysis (EDA) and data visualization.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify top-performing product categories.
- Compare sales across different regions.
- Understand customer segment performance.
- Explore monthly sales trends.
- Analyze the relationship between sales and profit.
- Discover useful business insights from data.

## 📊 Dataset Information

The dataset contains 30 fictional sales transaction records.

| Column | Description |
|---|---|
| Order_ID | Unique order identifier |
| Order_Date | Date of order |
| Customer_Name | Customer name |
| Segment | Customer segment |
| Region | Sales region |
| Category | Product category |
| Product | Product name |
| Quantity | Number of products sold |
| Sales | Total sales amount |
| Profit | Profit or loss amount |

*Note: This project uses fictional sample data for educational and portfolio purposes.*

## 📈 Data Visualizations

The project includes six visualizations:

1. Sales by Product Category
2. Sales by Region
3. Sales by Customer Segment
4. Profit by Product Category
5. Sales Trend Over Time
6. Sales vs Profit

```bash
cd Global-Superstore-Sales-Analysis-Using-Python
```
